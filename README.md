# Pipeline

Mini CRM de prospection mono-utilisateur. Voir [INTENT.md](./INTENT.md).

## Stack

Next.js (App Router) · TypeScript · Tailwind · shadcn/ui · Vitest · pnpm

## Démarrage

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm test
pnpm lint
pnpm build
```

Branche de travail : `dev`.
